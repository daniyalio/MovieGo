## In order to run this project, one needs an api key from www.themoviedb.org.
- Sign up on www.themoviedb.org
- Click on the profile, then setting.
- Go to the api and request for the generation of an api key
- Now,Go to api.js (located in "services" folder)
- Copy your api key and paste here
    Sample:
    const API_KEY = "...................";
- Then all set.
